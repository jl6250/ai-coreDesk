01 系统背景与核心建设指标

在跨境金融、互动娱乐及高频业务出入金场景下，客服系统承载着大额资金咨询（充提、打码量、流水对账）与敏感客诉的高压冲击。传统方案常因大模型数字幻觉引发超额承诺、高并发查询拖垮核心账务数据库，以及客诉危机响应迟钝导致严重业务事故。

CoreDesk 核心设计铁律： 大模型仅担任“事实翻译官与多语言表达器”，绝不允许由概率模型推断或自行编造任何金额、打码量缺口或出款承诺。所有权威数据均来自业务只读网关。
目标维度 传统智能客服现状 CoreDesk 工业级落地标准 达成衡量机制
资金安全防线 单体 LLM 直接回答，频发虚假承诺 确定性规则 + 只读代理 + 发送前脱敏质检 违规包赔承诺 100% 拦截并审计
高并发账务性能 直查主业务库，引发行锁与死锁 10W TPS CQRS 只读投影镜像 压测下核心写事务零干扰，P99 < 15ms
服务时效 (SLA) 大模型首字生成 2~5 秒，排队阻塞 JEV 决策 < 1ms，Auto-Pilot < 50ms 分级放行门禁，低风险无需等 LLM 生成
多渠道与协同 各平台孤立，人工与机器人抢话脱节 统一 IM 网关 + ACD 技能组 + 班长席密语 双向无损热切换，强插接管无缝协同

04 Phase 1 详细设计: Copilot 辅助化与安全底座

4.1 毫秒级多语言识别与越狱拦截

在 jev_gateway.py 中，前置识别引擎结合轻量正则与字符集特征，在零外部网络调用损耗下实现高精度判定：

app/services/jev_gateway.py (多语言快速探测核心) 
def detect_language(self, text: str) -> str:
    # 泰文字符范围 (Thai Unicode Block)
    if re.search(r"[\u0e00-\u0e7f]", text):
        return "th"
    # 汉字范围 (CJK Unified Ideographs)
    if re.search(r"[\u4e00-\u9fa5]", text):
        return "zh"
    # 越南文特征声调字符 (Vietnamese tone marks)
    if re.search(r"[àáảãạăằắẳẵặâầấẩẫậèéẻẽẹêềếểễệìíỉĩịòóỏõọôồốổỗộơờớởỡợùúủũụưừứửữựỳýỷỹỵđ]", text, re.IGNORECASE):
        return "vi"
    # 默认判定为英语
    return "en"

4.2 CQRS 账务只读直连架构

针对提现流水、打码量对账等高频压力，系统与交易主库严格实施物理级读写分离：

只读原则： 客服系统禁止向交易账本发起任何写锁请求。提现卡单诊断时，系统在内存中根据 required_turnover 与 completed_turnover 实时试算差额。

09 IM 全渠道接入网关 (Telegram / WhatsApp / LINE / Web)

IMChannelGateway 提供统一的协议归一化与出站消息分流服务：

  • Telegram Bot：基于 Webhook Secret 与官方 Update 对象解析。
  • WhatsApp Cloud API：支持 Meta 官方验证握手（hub.challenge）与 HMAC-SHA256 签名校验。

  • Web / App 浮窗：支持 SSE 流式推流与标准 WebSocket。

10 ACD 智能排队调度与班长席监控协同

针对企业级服务运营，中台集成了三大协同引擎：

  1. ACD 技能组路由：包含财务专席组 (finance_desk)、VIP 尊享管家组 (vip_support)、东南亚多语种组 (sea_multilang_desk) 与综合业务组 (general_desk)，按技能匹配与最小负荷（Least Loaded）优先分配。
  2. 班长席内部密语 (Whisper)：主管可在会话监控中向坐席发送实时指导，该卡片在坐席端显眼高亮，客户端严格隔离不可见。
  3. 会话强插接管 (Barge-in)：面对复杂或恶性客诉，班长席一键强插接管，原坐席自动转为只读旁听。

12 10W TPS 隔离与零资损防护保障

资金与权限三大铁律：
  1. 对象归属校验：服务端依据鉴权上下文严格校验查询订单的归属者，禁止依赖用户文本指定的 ID。
  2. 只读网关白名单：查询接口仅暴露业务允许字段，内部风控敏感标签（如涉诈排查码）绝对不对外输出。
  3. 质检脱敏不放过：即便大模型产生错误输出，后置质检模块依然在网络层强行抹除卡号并阻断赔偿承诺。
